# Результат на конкурсном наборе

Файлы этой папки — то, что раздел 7.2 ТЗ требует приложить к финальной сдаче:
выгрузка результата на конкурсном наборе `data/samples/dataset_lct2026.geojson`.

Они не собираются руками и не правятся: каждый получен из работающего сервиса
одним запросом и воспроизводится за двадцать две секунды.

| Файл | Что это | Как получен |
|---|---|---|
| `result_lct2026.geojson` | результат обычного расчёта: три варианта со всеми объектами раздела 10 ТП | `GET /api/v1/jobs/{id}/result.geojson` |
| `result_lct2026_depth.geojson` | то же с дополнительной задачей по глубине: Z-координаты и объекты `depth_crossing` | тот же запрос по расчёту с `withDepth: true` |
| `statement_lct2026_best.csv` | ведомость объёмов работ по лучшему варианту — таблица для Excel | `GET /api/v1/jobs/{id}/statement.csv` |
| `presentation/index.html` | презентация к защите, 13 слайдов | открыть в браузере; `Ctrl+P` → «Сохранить как PDF», альбомная, поля «нет», фоновая графика включена |

## Как воспроизвести

```bash
cp .env.example .env
docker compose up -d --build
```

Дальше — интерфейс на http://localhost:3000: загрузить набор, нажать «Запустить
расчёт», выгрузить результат. То же через API описано в Swagger на
http://localhost:8080/swagger-ui.html.

Проверка того, что всё это собирается и работает на чужой машине с нуля:

```bash
bash ops/clean_room_check.sh
```
