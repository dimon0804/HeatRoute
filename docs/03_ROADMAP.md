## Риски

| Риск | Проявление | Что делаем |
|---|---|---|
| Проверочный набор плотнее конкурсного | граф видимости строится долго | раздельные радиусы видимости (300 м между препятствиями, 2000 м от терминалов), построение рёбер в несколько потоков; при необходимости радиусы уменьшаются параметром без пересборки |
| Проверочный набор полнее по атрибутам | ветка «атрибуты есть» менее обкатана | обе ветки реализованы и покрыты тестами с самого начала |
| Типы ограничений, которых мы не видели | правило по умолчанию слишком строгое | словарь псевдонимов в конфигурации, тип попадает в диагностику, правило меняется без пересборки |
| Эвристика даёт заметно неоптимальный результат | высокая стоимость варианта | восемь запусков с разными стартовыми терминалами, локальное улучшение по деньгам, отсечение ветвей без потребителей; инварианты результата закреплены тестами |
| На конкурсном наборе лучший вариант обходится без реконструкции существующей сети | нечего показать по пункту 6 сценария демонстрации | добавить вариант «минимальная длина», который не избегает реконструкции; либо показать режим `existing-flow-mode: CAPACITY_FRACTION` |
| Демонстрация на чужой машине | что-то не поднялось | единственная команда запуска, проверка на чистой машине заранее |
