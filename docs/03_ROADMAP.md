## Риски

| Риск | Проявление | Что делаем |
|---|---|---|
| Проверочный набор плотнее конкурсного | граф видимости строится долго | `RoutingSpace` за интерфейсом, запасная реализация на триангуляции; ограничение радиуса видимости |
| Проверочный набор полнее по атрибутам | ветка «атрибуты есть» менее обкатана | обе ветки реализованы и покрыты тестами с самого начала |
| Типы ограничений, которых мы не видели | правило по умолчанию слишком строгое | словарь псевдонимов в конфигурации, тип попадает в диагностику, правило меняется без пересборки |
| Эвристика даёт заметно неоптимальный результат | высокая стоимость варианта | локальное улучшение, сверка с полным перебором на малых сценах в тестах |
| Демонстрация на чужой машине | что-то не поднялось | единственная команда запуска, проверка на чистой машине заранее |
